# Drowned Village pet icons

The five imported pets' icons (`Config/GearAssets.pets`), **rendered from
the models themselves** rather than drawn: each pet was stood on a flat
magenta card in Studio's Edit view at the hatchery's three-quarter turn,
captured, keyed out and cut to a 512 px square. They are 1:1 with the
models by construction.

The other twenty-four pets' icons are drawn pixel art from Claude Design
(`assets/concepts/pets/forest`, `.../wilfs`). These five stand in until
there is drawn art for them; swapping one is a single id in
`Config/GearAssets.pets`.
