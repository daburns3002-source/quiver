# Arrow Legends — upgrade cards

Every upgrade card in the game (44), by the class that can draw it, then rarity.
Rarities, lowest to highest: Common, Uncommon, Rare, Epic, Legendary, Mythic.

## Shared (every class) — 12 cards

| Card | Rarity | What it does |
|---|---|---|
| Heal | Common | Restore some of your health now. |
| Lightfoot | Common | Move faster. |
| Strength | Common | Raise attack damage. |
| Vitality | Common | Raise max HP. |
| Agility | Uncommon | Chance to dodge attacks. |
| Mending | Uncommon | Regenerate HP over time. |
| Precision | Uncommon | Raise critical hit chance. |
| Blaze | Rare | Arrows set enemies on fire. |
| Bloodthirst | Rare | Heal a little on every kill. |
| Deadly Strike | Rare | Critical hits deal more damage. |
| Momentum | Rare | Attack speed rises while moving. |
| Second Wind | Mythic | Revive once with half your HP. |
